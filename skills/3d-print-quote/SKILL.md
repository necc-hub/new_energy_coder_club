# 3D 打印报价系统

## 工作流程

1. **提取切片数据**：从用户提供的切片截图（ReadMediaFile 读取）或文本中提取：
   - 总耗材重量（克，**含支撑**，用"总计"行而非"模型"行）
   - 总打印时长（换算成小时，如 1d21h22m = 45.37h）
   - 支撑占比（支撑克数/总克数；>20% 时后处理人工按 60 分钟计）
   - ⚠️ 切片软件里的"总成本"字段是按软件默认料价算的，**一律忽略**，用用户实际料价重算

2. **确认参数**：耗材单价（元/kg）和运费。用户未提供时主动询问；顺丰默认约 30 元。

3. **运行计算脚本**（禁止手算，必须用脚本保证确定性）：

```bash
python "<skill_dir>/scripts/quote.py" --weight 559.9 --hours 45.37 --filament-price 50 --shipping 30
```

   支撑占比高时加 `--labor-min 60`。加 `--json` 可得结构化输出。

4. **输出报价单**，格式如下（表格化呈现）：
   - 任务概况表：克重、时长、盘数、支撑占比
   - 成本明细表：材料费/电费/机器折旧/人工/运费/硬成本合计
   - 三档报价表：保本价（硬成本+运费）、**合理价（推荐，约 1.3 倍利润率）**、友情价
   - 结论：一句话给出推荐报价及理由（时长长、支撑多、克单价是否偏离行情）

## 定价参考（市场行情）

- 常见代工克单价 0.25~0.35 元/g；脚本会折算克单价并自动提示偏离
- 时长超 24h 的大件、支撑占比 >20% 的件，报价应靠上限
- 低于保本价即贴钱，必须在结论中明确提示
