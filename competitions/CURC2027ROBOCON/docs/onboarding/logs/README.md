# 学习记录存放区

这里存放 27 赛季新人的学习记录。

---

## 目录结构

```text
logs/
├── mechanical/     # 机械组学习记录
├── electrical/     # 电控组学习记录
├── hardware/       # 硬件组学习记录
├── vision/         # 视觉组学习记录
└── operations/     # 运营组学习记录
```

---

## 如何添加自己的记录

1. 进入自己方向的目录，例如 `electrical/`。
2. 新建以你昵称命名的文件夹，例如 `electrical/darrenpig/`。
3. 在该文件夹下新建 markdown 文件，命名格式：

```text
<YYYYMMDD>-<主题>.md
```

示例：

```text
electrical/darrenpig/20250701-stm32-gpio.md
```

4. 参考 [../templates/learning-log-template.md](../templates/learning-log-template.md) 写内容。
5. 提交 Pull Request。
