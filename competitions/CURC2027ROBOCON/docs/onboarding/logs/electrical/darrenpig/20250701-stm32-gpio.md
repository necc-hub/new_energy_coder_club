## 过程记录

### 步骤 1：理解 GPIO 模式

- 输入：浮空输入、上拉输入、下拉输入、模拟输入
- 输出：推挽输出、开漏输出、复用推挽、复用开漏

### 步骤 2：使用 HAL 库配置

在 `MX_GPIO_Init()` 中配置引脚模式、速度、上下拉。

### 步骤 3：点亮 LED

```c
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET);
HAL_Delay(500);
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);
HAL_Delay(500);
```

## 遇到的问题

| 问题 | 尝试过的方法 | 是否解决 |
|------|-------------|---------|
| LED 不亮 | 检查引脚定义、检查限流电阻 | 是 |
| 延时不对 | 确认系统时钟配置正确 | 是 |

## 收获与总结

GPIO 是 STM32 最基础也是最常用的外设。HAL 库虽然封装了一层，但理解底层寄存器原理更重要。
