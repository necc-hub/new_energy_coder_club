# 新成员学习进度区

> 参考 26 赛季做法，每位新人在这里创建以自己姓名命名的 markdown 文件，定期更新自己的学习进度。

---

## 提交方式

1. 复制 [新人进度模板.md](./新人进度模板.md)。
2. 新建文件：`members/<你的姓名>.md`，例如 `members/朱佩韦.md`。
3. 填写你的基本信息和当前学习进度。
4. 提交 Pull Request。

---

## 文件命名

```text
members/<姓名>.md
```

或：

```text
members/<姓名>-首次提交.md
```

---

## 更新频率

- **首次提交**：加入团队后尽快提交第一版。
- **持续更新**：每 1-2 周更新一次，记录新学内容、遇到的问题和下一步计划。

---

## 与 logs 的区别

| 区域 | 用途 | 文件形式 |
|------|------|---------|
| `members/<姓名>.md` | 个人总进度看板 | 一个文件，持续更新 |
| `logs/<方向>/<昵称>/<日期>-<主题>.md` | 每篇详细学习记录 | 多个文件，按次记录 |

建议两者配合使用：`members/<姓名>.md` 是你的总进度表，`logs/` 里放具体每次的学习记录。
