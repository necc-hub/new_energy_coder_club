## 团队方向

| 方向 | 说明 | 目录 |
|------|------|------|
| 机构 SIG | 机械设计 + 电控开发 | [机构SIG](./机构SIG/) |
| 视觉 SIG | 视觉算法 + 硬件驱动 | [视觉SIG](./视觉SIG/) |
| 运营 SIG | 宣传 + 赞助 + 赛务 | [运营SIG](./运营SIG/) |

### 机构 SIG 分组

- [机械组](./机构SIG/机械组/)：机械设计、加工图纸、装配说明
- [电控组](./机构SIG/电控组/)：电路设计、嵌入式开发、联调支持

### 视觉 SIG 分组

- [视觉组](./视觉SIG/视觉组/)：视觉算法、上位机开发、数据集管理
- [硬件组](./视觉SIG/硬件组/)：相机/传感器硬件、驱动接口、供电通信
