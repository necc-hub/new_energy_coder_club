- [视觉组](./视觉SIG/视觉组/)：视觉算法、上位机开发、数据集管理

## 赛季目标

正式竞赛目标待 27 赛季规划会议确认。本仓库先执行以下工程资产目标：

| 方向 | 必须沉淀的基线 | 验证方式 | 当前状态 |
|------|---------------|----------|----------|
| 机械 | 装配版本、关键图纸、BOM、装配说明 | 版本文件可打开，装配步骤可复核 | 待负责人补基线 |
| 电控 | 硬件清单、固件版本、接线与烧录说明 | 最小固件可构建或注明硬件实测环境 | 待负责人补基线 |
| 视觉 | 依赖版本、数据来源、最小推理 Demo | 一条命令运行，记录模型与输入版本 | 待负责人补基线 |
| 运营 | 赛务清单、素材索引、赞助与致谢记录 | 文件可定位，外部素材注明来源与授权 | 待负责人补基线 |

各 SIG 的“当前状态”只有在链接到具体版本文件或验证记录后才能标为完成；学习日志不直接等同于工程验收。
