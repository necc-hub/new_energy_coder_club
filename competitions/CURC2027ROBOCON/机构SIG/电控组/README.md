## 新人学习路线

> 以下内容来自 27 赛季招新文档。要做嵌入式项目，必须得会 STM32 才能上手，不然不好派活。

### 前置要求

- [ ] STM32 必须会
- [ ] 中科大 RM 电控课至少看一遍起步

### 第一阶段：导论课

- [ ] [中科大 RM 电控合集：电控入门导论](https://www.bilibili.com/video/BV1d7jbefEee)
- [ ] [中科大 RM 电控合集：嵌入式开发的未来展望](https://www.bilibili.com/video/BV1d7jbefEee)

### 第二阶段：STM32 基础

任选其一入门，最终落点在中科大 RM 电控课：

- [ ] 野火 STM32 基础版（约 10h，到中断定时器、点灯小项目、古法编程）
- [ ] 野火的书
- [ ] keysking 的 STM32 HAL 库教程（节奏好，不枯燥）
- [ ] 江协科技 STM32 教程

> 有基础或想快速上手，可以直接上中科大；看不进野火，先看 keysking。

### 第三阶段：面试准备

- [ ] 复习 STM32 基础
- [ ] 了解通讯协议、外设、算法等嵌入式相关知识
- [ ] 整理已有项目（竞赛项目 / 开源广场复刻项目）

### 面试时间

- 预计九月开学进行电控基础面试
- 目的：了解基础、见个面、一起聊聊后续学习安排

### 器材建议

- STM32 用最小系统板玩就行
- 贵的器材可以咸鱼买了学完再卖掉
